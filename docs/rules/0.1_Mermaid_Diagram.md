# Sorcerer Documentation

````mermaid
flowchart TD

A[Start Game-Turn] --> B[First Player<br/>Movement & Conjuration]

%% Movement & Conjuration (stacked vertically)
B --> B1[Move Units]
B1 --> B2[Teleport Sorcerers]
B2 --> B3[Conjure Units]
B3 --> B4[Restore Units]
B4 --> B5[Remove PIN Markers]
B5 --> B6[Create Vortexes]
B6 --> B7[Fling Magic Bolts<br/>Resolve Immediately]

%% Joint Attrition
B --> C[Joint Attrition Phase]
C --> C1[Draw 2 Colors]
C1 --> C2[Roll Attrition<br/>Affected Magical Units]
C2 --> C3[Apply Attrition Results]

%% Joint Combat
C --> D[Joint Combat Phase]
D --> D1[Identify Contested Hexes]
D1 --> D2[Compute Strengths]
D2 --> D3[Add Color Augmentation]
D3 --> D4[Determine CRT Line]
D4 --> D5[Roll Die]
D5 --> D6[Apply Loss Priority]

%% Second Player Turn
D --> E[Second Player<br/>Movement & Conjuration]
E --> E1[Repeat Movement Steps]

%% Second Attrition
E --> F[Joint Attrition Phase]
F --> F1[Draw 2 Colors]
F1 --> F2[Roll Attrition]
F2 --> F3[Apply Results]

%% Second Combat
F --> G[Joint Combat Phase]
G --> G1[Repeat Combat Steps]

%% End of Turn
G --> H[Interphase]
H --> H1[Advance Turn Marker]
H1 --> I[End Game-Turn]
```
