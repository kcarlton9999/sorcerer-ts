# Sorcerer Documentation

## [1.0] INTRODUCTION

**Sorcerer** is a game which takes place in an alternate universe where magic actually works. There are three basic categories of units: Sorcerers (of various powers), human infantry, and magical units (trolls, demonic infantry and air dragons); and seven types of magic, each represented by an actual color.
